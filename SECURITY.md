# Security Policy

## Reporting Security Issues

We take the security of AlphaGuard seriously. If you discover a security vulnerability or sensitive information exposure in this repository, please report it responsibly.

### How to Report

- **Email**: Send vulnerability reports to `tchacko615@gmail.com`.
- **Details to Include**:
  - A description of the issue and potential impact.
  - Steps to reproduce or proof-of-concept.
  - Affected components, files, or configurations.
- **Response Target**: We will acknowledge receipt within 48 hours and provide an assessment or fix timeline as soon as practical.

Please do not open public GitHub issues or discussions for sensitive security disclosures.

## Scope and Intent

AlphaGuard is a local financial research and educational laboratory evaluating decoupled multi-agent architectures (trade proposal vs. deterministic downside-risk veto). It is:
- **Not** a live trading or production brokerage platform.
- **Not** configured to execute live market transactions or store custodial assets.
- Intended for local replay, testing, and research environments.
